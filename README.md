## 🧠 真实案例：训练数据的认知偏差

> 2026-08-14，作者亲手绘制标准"8"（上圈+下圈），AI以 **98.09%置信度**识别为"9"。

**发生了什么**：手绘数字的8x8点阵，人眼一看就是"8"，但AI非常自信地说"9"。

**为什么**：AI的认知100%由训练数据决定——训练数据里"9"的字形（上圈+直身）与作者绘制的图案高度吻合，而训练数据里的"8"可能长得不同。AI没有"客观真理"，只有"数据里的样子"。

**启示**：
- 数据决定认知：模型再强，也是训练数据塑造的
- 数据质量 = 模型质量：想让它认对"8"，先给它看对的"8"
- 这就是为什么开源社区如此重视数据集（如MNIST/ImageNet）

*这个"错误"不是缺陷，是AI工作原理的最佳教学案例。*
